# Lighty Client (Fabric 1.21.11)
Autor: L1ghtyyy

Prawy Shift - menu: moduly (Tracery, Nametagi, Hitboxy, Xray, NoPush), bindy (kliknij "Bind",
nacisnij klawisz, Backspace = usun), 5 motywow, opcje nametagow, hitboxow i xraya.
Ustawienia zapisuja sie same w .minecraft/config/lighty_client.json
(tam mozesz tez dopisac wlasne bloki do xraya w "xrayCustom", np. "minecraft:chest").
